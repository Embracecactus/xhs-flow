# 个人技能库与项目固定副本

2026-10-14 将个人和项目技能统一整理到私有库 [Embracecactus/codex-skills](https://github.com/Embracecactus/codex-skills)。库按内容制作、平台发布、嵌入式与设备、软件工程、知识管理五类管理，提供分类安装、依赖检查、冲突备份和固定提交外部组件下载。

本项目采用其中六个自维护入口的固定副本：`self-media-workflow`、`content-strategy`、`content-authoring`、`content-analytics`、`technical-handdraw-video`、`multi-platform-publish`。抖音旧入口仅跳转到统一发布技能；旧七个 self-media 上游目录保留哈希核验及许可，不再默认调用。未改动全局 `.agents/.codex` 安装。

对应合并：总控+交付→self-media-workflow；策略+趋势→content-strategy；简报+平台文案→content-authoring；数据复盘→content-analytics。抖音操作细节进入多平台参考，公众号/视频号独立建项、逐篇微信验证、日期改变通知、后台折叠等经验一并保留。

新电脑按库 README 克隆并安装；技能源码可复制，账号登录、宿主控制工具、中文字体、剪映音色和硬件驱动仍由新电脑提供。此项目生产路径在 `.local/skills/` 使用的手绘引擎及字幕/音效适配不随技能库分发；已有任务继续依照自身 `production_engine`、版本和审核记录恢复。

本库只管理通用流程和必要源码，不包含 `workspace/xiaohongshu`、`workspace/douyin`、真实账号、成片或后台证据。历史授权从用户任务和项目记录读取，不固化进通用Skill。项目中的内容、脚本及未提交工作没有随新库一并提交。
