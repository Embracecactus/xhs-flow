# Content strategy

Use for account positioning, columns, topic pools, capacity-aware calendars, public trend research, keyword research, or competitor structure analysis. Do not use it merely to draft one confirmed post.

## Establish the decision context

Read available account material, past work, performance data, and user sources before asking questions. Clarify only what changes the result: audience, business/content goal, platform, available first-hand evidence, capacity, timing, and exclusions.

Write a positioning promise that can reject topics: who benefits, what recurring value they receive, and why the account can support it. Treat proposed ratios, cadence, and targets as hypotheses when no baseline exists.

## Research without copying

Prefer user evidence, original documents, official information, and public posts. For changing facts, check current primary sources. Keep a bounded sample and record source, date, content form, observable signal, and limitation.

Analyze the promise, opening, evidence order, cover/first-screen role, action, and visible audience questions. Do not reproduce a competitor's wording or claim a single high-performing item proves a rule.

## Produce usable planning artifacts

For each topic, state the audience, one-sentence claim or hook, objective, platform role, first-hand evidence, missing evidence, time window, cost, and risk. Group durable topics into a small number of columns with a stopping condition.

Build calendars from actual capacity first. Leave room for timely work and vary only one important experiment per cycle. Separate observation from causal conclusion.

Return the positioning, chosen assumptions, topic/column plan, calendar if requested, evidence gaps, and next validation action.
