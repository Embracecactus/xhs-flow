# 微信公众号

以下来自官方网页操作案例，控件名称、长度和封面规格仅作定位线索；以现场界面为准。公众号素材库、公众号消息和视频号是三个独立对象。

1. 首页新的创作选择视频。视频选择器的“本地上传”可能先打开“添加视频”表单，再点“上传视频”才出现系统文件对话框。上传后等待处理并保存素材；系列可以先保存各集素材，再从已有素材选择，避免重复上传。
2. 封面先在图片库上传并确认出现，不能仅依据按钮 enabled 判断完成。案例中分别有视频消息16:9、方形1:1、视频16:9裁剪；核对各槽位和标题安全区。上传前后的标题上限可能不同，按当前限制编辑，不静默截断正文。
3. 编辑标题和正文。可见过标题 Edit 的 `js_article_title` 与正文 `ProseMirror`，但不能当永久选择器。查看正文全段及实际关联视频；同页“创作来源”和“未添加”可能有重名控件，按行/容器消歧。按内容真实情况填写 AI/来源声明。
4. 若视频号已单独投稿，关闭不需要的同步视频号，避免重复分发。编辑器“发表”先进入发表向导，向导里的最终“发表”是另一动作；用对话框及相邻“取消”确认按钮归属。
5. 在向导设置定时。选择未来日期可能自动启用群发通知，并出现第三种分组通知；日期变更后重新查看并恢复任务要求的通知设置。不要只检查定时开关。小时、分钟列表可能有同名数字，按所属列定位；选择小时后重新获取分钟控件。
6. 继续发表的普通确认与微信扫码验证分别记录。可能每篇都需微信验证；前一篇扫码不代表下一篇获准。出现验证请用户在微信完成，保留待办和提交信息；不要重新打开向导反复提交。
7. 验证后编辑页空白或跳转不明时，先回已有首页查后台。列表可能只显示两篇，需“显示全部”。按每篇标题、封面和计划时间核对全部指定内容；不要把其他文章的定时当作本批成功。

保存的定时和审核状态分别记录。素材库完成不能登记为消息发表；公众号完成也不能替代视频号结果。权限、每日额度、通知受众以当前账号为准。
