# 抖音

先核对创作者账号及当前投稿版本，完整等待上传/转码。保留段落、用户指定话题，并从平台候选中确认话题实体，不能只有字符串 `#标签`。

封面槽位分别操作；案例出现4:3横封面与3:4竖封面，以当前要求为准。每个槽位保存后回到表单回读。若组合保存卡住，保留文案和已上传视频，仅重新处理有问题的封面；案例中曾改用 JPEG 后成功，但不能据此把 PNG 当作确定根因或永久禁用。

按实际内容选择 AI/原创声明。自动化 Select 返回成功后仍可能没选中，必须读当前状态；默认同步分发按本次目标核对。原生定时的日期、小时、分钟分别回读。

最终发布一次后进入内容管理，按标题/封面/时间匹配。置顶旧稿可能排在第一条，不能取列表首条当新稿。后台“审核中”可与保存定时并存；上传4K不代表平台播放端已提供4K。结果不明先查当前内容管理，不刷新未保存表单重传。
