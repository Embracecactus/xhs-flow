资料整理 / 演示样稿02 / 06

收藏时
多留四项

原文地址与作者
尽量回到原始发布页面。

发布时间与查看时间
发布日期找不到就记“未知”。

支持哪一句话
写出原文位置或章节。

能不能公开使用
记录授权、许可和署名要求。

链接是入口；这些信息帮助你判断，资料是否适合这篇笔记。

资料整理 / 演示样稿03 / 06

事实和建议
分开写

可核验事实

示例项目文档要求记录来源，并区分事实、判断和建议。

本文的建议

整理时，为每条重要结论建立一张证据卡。

前者能回到原文核对。
后者是工作方法，仍需自己试用。

没有实测材料，就写资料整理；没有用户反馈，就不补写“大家都说好用”。

资料整理 / 演示样稿04 / 06

一次整理
走这三步

01

找到原始发布

先确认是谁、何时、在什么范围内说的。转载可作线索，关键结论回到原文。

02

写下可用结论

用自己的话整理，并记下原文章节。自己的推断另起一句说明。

03

留下待核对项

例如：版本是否改变、数据窗口是什么、图片是否允许公开使用。

资料整理 / 演示样稿05 / 06

这三种缺口
先别补全

01

没找到的数据

把空白保留下来。点赞不能替代阅读，公开互动也不是收入。

02

只有局部截图

保留上下文和观察时间。无法核对的数字，暂时不作为核心论据。

03

没有亲身经历

用“文档写明”“资料显示”等准确表述，不改写成“我试过”。
