# 演示待审：收藏资料，怎样留下可核验的来源

标题候选：
1. 收藏资料，怎样留下可核验的来源（方法入口，演示采用）
2. 写笔记前，给结论留一张证据卡（动作入口）
3. 找不到出处的资料，先别急着用（问题入口）

---

收藏了一篇文章，准备写笔记时，却只记得一句结论。原文有没有条件？数字是什么时间的？图片能不能用？这些问题靠回忆很难答准。

可以在收藏时多留四项：原文地址与作者、发布时间与查看时间、支持哪一句话、使用权利与署名要求。找不到的内容直接写“未知”。

这里的依据是一个公开内容工作流项目：它要求关键数字有来源，区分事实与判断，优先原始资料，并禁止编造体验。本文把这些原则整理成一张证据卡，是方法建议，不是平台要求。

写的时候分清两层：“文档写明”能回到原文核对；“我建议这样整理”是方法选择，不能冒充已有的效果结论。没有实测就做资料整理，没有反馈就不要补写用户评价。

证据卡可以这样填：
原文链接：____
发布时间 / 查看时间：____
支持的一句话 / 原文位置：____
不能证明什么：____
使用权利 / 待核对项：____
